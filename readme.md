
# web-сервис на базе docker docker compose
Приложение представляет собой простой web-service

+ Использованы docker как инструмент виртуализации сервисов 
+ docker compose для объединения сервисов в группу виртуальной локальной сети

# Backend сервис

Представляет из себя python скрипт формирующий данные и отправляемые клиенту
Включает и работает с библиотеками fastapi и uvicorn

# Proxy сервис

Берёт на себя задачу скрыть прямое обращение к backend что повышает безопасность
Более того живёт отдельно (в своей сети) что позволяет в перспективе масштабировать нагрузки если потребуется
